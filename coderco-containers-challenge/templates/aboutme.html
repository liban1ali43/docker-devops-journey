About This Project

CoderCo Containers Challenge — Built a multi-container Python Flask application integrated with Redis for visit counting. Used Docker multi-stage builds to optimize the application image and reduce unnecessary runtime dependencies. Configured Nginx as a reverse proxy and load balancer, and used Docker Compose to orchestrate the application and supporting services. Tested the complete environment locally.

I then containerized the application and Redis and used Docker Compose to run the services together.

I tested the application locally and verified that the Flask application could communicate with Redis and maintain the visit counter.
